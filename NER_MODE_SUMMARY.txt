1. WHAT IS NER (Named Entity Recognition)?
   Extract medical entities (drugs, diseases, symptoms) from user queries.
   
   Example: "What are side effects of Metformin?"
            → Extract: "Metformin" (DRUG entity)

2. NER IMPLEMENTATION (3-Tier Approach)
   
   PRIMARY: scispaCy NER
   ├─ Medical-specialized model (en_core_sci_md)
   ├─ Accuracy: 85%
   ├─ Confidence: 0.8
   ├─ Size: ~40MB
   └─ Location: backend/preprocessing/query_processor.py lines 36-107
   
   FALLBACK: Regex Patterns
   ├─ Pattern-based extraction
   ├─ Accuracy: 65%
   ├─ Confidence: 0.7
   ├─ Size: <1MB
   └─ Location: backend/preprocessing/query_processor.py lines 109-170
   
   ALTERNATIVE: BioBERT / Dictionary / Hybrid
   ├─ BioBERT: 92% accuracy, slow
   ├─ Dictionary: 98% accuracy, very fast
   ├─ Hybrid: 95% accuracy, medium speed

3. WHAT IS MODE DETECTION?
   Automatically determine if user is a PATIENT (lay language) 
   or DOCTOR (technical language).
   
   Example 1: "I have diabetes, is Metformin safe?"
              → PATIENT mode (personal pronouns, lay language)
   
   Example 2: "What is pathophysiology of Type 2 Diabetes?"
              → DOCTOR mode (technical terminology)

4. MODE DETECTION ALGORITHM (4 Steps)

   STEP 1: Check Technical Terminology (Strongest)
   ├─ Terms: pathophysiology, pharmacokinetics, contraindication, etc.
   ├─ If found → DOCTOR MODE (STOP)
   └─ Location: lines 228-244
   
   STEP 2: Check Personal Pronouns (Strong)
   ├─ Phrases: "I have", "I am", "my", "should I"
   ├─ If found → PATIENT MODE (STOP)
   └─ Location: lines 237-248
   
   STEP 3: Count Keyword Scores (Medium)
   ├─ Doctor keywords: 30+ professional terms
   ├─ Patient keywords: 20+ lay terms
   ├─ If doctor_score > patient_score (≥2) → DOCTOR
   └─ Location: lines 224-252
   
   STEP 4: Default to PATIENT (Safety)
   ├─ No strong indicators
   ├─ Default: PATIENT (simpler, safer language)
   └─ Location: lines 254-256

5. MODE KEYWORDS AT A GLANCE

   DOCTOR Keywords (Professional):
   ├─ Terminology: differential diagnosis, pathophysiology, 
   │               contraindication, pharmacokinetics, etiology
   ├─ Clinical: management of, treatment protocol, clinical guidelines,
   │            first-line therapy, mechanism of action
   └─ Specific: prescribe, efficacy, bioavailability, lab values

   PATIENT Keywords (Lay Language):
   ├─ Personal: I have, I am, my, should I, is it safe
   ├─ Simple: side effects, how long, is this normal
   └─ Concerns: what can I do, will it help, should I worry

6. NER + MODE WORKFLOW

   Input: User Question
          ↓
   NER Processing (Extract Entities)
   ├─ Try scispaCy → Success (95%): DRUG/DISEASE/SYMPTOM
   └─ Fallback regex → Lightweight extraction
          ↓
   Mode Detection (Patient vs Doctor)
   ├─ Check technical terms
   ├─ Check personal pronouns
   ├─ Score keywords
   └─ Default to patient
          ↓
   Output: Processed Query with Entities + Mode
   ├─ Entities: ["Metformin" (DRUG)]
   ├─ Mode: PATIENT
   └─ Strategy: HYBRID retrieval

7. HOW RESPONSES DIFFER BY MODE

   PATIENT Mode Example:
   Q: "What are side effects of Metformin?"
   A: "Common side effects include nausea, stomach upset, and diarrhea.
       These usually go away after a few days. Contact your doctor if
       they persist or worsen."
   
   DOCTOR Mode Example:
   Q: "What are pharmacokinetic properties of Metformin?"
   A: "Metformin undergoes minimal hepatic metabolism (~5%) and is 
       excreted unchanged in urine. Peak plasma concentration occurs 
       in 2-3 hours with oral bioavailability of 50-60%..."
