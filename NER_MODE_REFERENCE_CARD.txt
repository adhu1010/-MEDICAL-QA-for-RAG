┌──────────────────────────────────────────────────────────────────────────────┐
│ 👥 MODE DETECTION (Patient vs Doctor)                                       │
│ What: Automatically detect if user is a patient or medical professional    │
│ Where: backend/preprocessing/query_processor.py                             │
└──────────────────────────────────────────────────────────────────────────────┘

4-STEP ALGORITHM (Processing Order)

STEP 1️⃣ CHECK TECHNICAL TERMS (Strongest)
  Keywords: pathophysiology, pharmacokinetics, contraindication, differential,
            etiology, therapeutic index, bioavailability, efficacy
  ├─ Found? → DOCTOR MODE ✅ (Return immediately)
  └─ Not found? → Continue to Step 2
  
  Lines: 228-244
  Example: "What is pathophysiology?" → DOCTOR (has technical term)

STEP 2️⃣ CHECK PERSONAL PRONOUNS (Strong)
  Phrases: "I have", "I am", "my ", "should I"
  ├─ Found? → PATIENT MODE ✅ (Return immediately)
  └─ Not found? → Continue to Step 3
  
  Lines: 237-248
  Example: "I have diabetes, is it safe?" → PATIENT (has "I have")

STEP 3️⃣ COUNT KEYWORD SCORES (Medium)
  Doctor keywords (30+): differential diagnosis, management of, treatment 
                         protocol, clinical guidelines, first-line therapy, etc.
  Patient keywords (20+): side effects, is it safe, will it help, how long, 
                          should i worry, in simple terms, etc.
  ├─ Score each type: doctor_score, patient_score
  ├─ If doctor_score > patient_score AND doctor_score ≥ 2
  │  → DOCTOR MODE ✅
  └─ Otherwise → Continue to Step 4
  
  Lines: 224-252
  Example: "What are first-line therapies?" → DOCTOR (2+ professional keywords)

STEP 4️⃣ DEFAULT TO PATIENT (Safety)
  When: No strong indicators found
  ├─ No technical terms
  ├─ No personal pronouns
  ├─ No keyword majority
  └─ → PATIENT MODE ✅ (Safe default)
  
  Lines: 254-256
  Example: "What is diabetes?" → PATIENT (default, no indicators)

MODE DECISION TREE
  Question
    ↓
  ┌─ Has technical terms? YES → DOCTOR
  │
  └─ NO
    ├─ Has personal pronouns? YES → PATIENT
    │
    └─ NO
      ├─ doctor_score > patient_score ≥ 2? YES → DOCTOR
      │
      └─ NO → Default PATIENT

DOCTOR KEYWORDS
  Technical:       differential diagnosis, pathophysiology, contraindication,
                   pharmacokinetics, etiology, therapeutic index
  Clinical:        management of, treatment protocol, clinical guidelines,
                   first-line therapy, mechanism of action
  Professional:    prescribe, efficacy, bioavailability, half-life,
                   monitoring parameters, dosing regimen

PATIENT KEYWORDS
  Personal:        I have, I am, my, me, should I, can I
  Lay terms:       side effects, is it safe, will it help, how long
  Concerns:        should I worry, is this normal, what can I do,
                   in simple terms, in plain english

QUICK INDICATORS
  DOCTOR indicators:
    ✓ "pathophysiology", "pharmacokinetics", "contraindication"
    ✓ "first-line", "diagnostic criteria", "clinical manifestations"
    ✓ Asks about mechanism, efficacy, half-life
  
  PATIENT indicators:
    ✓ "I have", "my ", "should I"
    ✓ "side effects", "is it safe", "how long"
    ✓ Personal pronouns and lay language
