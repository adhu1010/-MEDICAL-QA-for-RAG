👥 MODE DETECTION
════════════════════════════════════════════════════════════════════════════════

Algorithm: 4-Step Detection Process
├─ File: backend/preprocessing/query_processor.py (lines 172-256)

STEP 1: Check Technical Terminology
├─ Terms: pathophysiology, pharmacokinetics, contraindication, etc.
├─ If found: DOCTOR MODE → RETURN
├─ Lines: 228-244

STEP 2: Check Personal Pronouns
├─ Phrases: "I have", "I am", "my", "should I"
├─ If found: PATIENT MODE → RETURN
├─ Lines: 237-248

STEP 3: Keyword Scoring
├─ Count doctor keywords (professional)
├─ Count patient keywords (lay)
├─ If doctor_score > patient_score ≥ 2: DOCTOR MODE
├─ Lines: 224-252

STEP 4: Default to PATIENT
├─ Safety default for unknown cases
├─ Simpler, more cautious language
├─ Lines: 254-256

Example:
Input: "I have diabetes, what should I take?"
├─ Technical? NO
├─ Personal pronouns? YES ("I have")
└─ Result: PATIENT MODE ✅
